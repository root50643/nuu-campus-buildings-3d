# 國立聯合大學校園建築 3D 模型

本專案收錄國立聯合大學建築物的 3D 模型、可編輯原始檔與實際模型預覽。說明與建築名稱使用繁體中文。

目前已完成並收錄 **國鼎圖書館**。其餘建築正在整理公開資料與建模範圍，尚未完成，這裡不宣稱已涵蓋全校建築。

## 檔案組織

每棟建築置於 buildings 下的獨立資料夾，保留自己的繁體中文說明、STL、Blender 檔案、建模程式、驗證結果與圖片。後續只會將完成並檢查過的模型標示為已完成。
